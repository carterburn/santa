To make the stack, start with mmap 10MB (1024*1024*10). Get the end address of
teh stack (addr + size). Then, when you build it up you build it in reverse in
this order:
path string (actual bytes of the string)
env var strings (with null bytes!)
argv strings
auxv strings (at_platform and at_random)
16 byte align by pushing zeros at this point
push the auxv
push a 0
push env var addrs 
push 0
push argv pointers / addrs
push argc

Way they did it was to save off the difference from where the string was pushed.
So, stack end address - len of stack at the moment you push. That should be the
address

We could probably also push entire usize's if we wanted to, but the strings may
be difficult. 

I think that is the way to do it but I don't want you looking!
